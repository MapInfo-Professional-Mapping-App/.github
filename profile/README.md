## Overview
MapInfo Professional for Windows — often searched for under its shorter nickname, MapInfo Pro — gives analysts and planners a desktop environment for turning location-based data into maps they can explore and edit. It links a live data table to the map view, so selecting a record highlights its feature on the map and vice versa. Beyond drawing and styling maps, it supports the kind of spatial analysis — buffers, overlays, distance queries — that turns a map from a picture into an analysis tool.

## Features
**Thematic mapping.** Shade or scale map features by an attribute's value to reveal patterns at a glance. **Spatial analysis.** Run buffer, overlay, and proximity queries against your layers. **Linked data table.** Keep the map and its underlying records in sync as you work. **Format support.** Bring in a range of common vector and raster file types. **Workspace files.** Save layers, styling, and queries together for later reuse.
